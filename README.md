# Blinkit Sales & Outlet Performance Dashboard

An end-to-end Power BI dashboard analyzing sales performance across Blinkit's outlet network, built during a Data Analytics internship at Rooman Technologies. The dashboard surfaces revenue trends, outlet performance, and inventory insights through interactive visuals.

## Tools Used
- **Power BI** — KPI cards, donut charts, bar visuals, interactive slicers, time-series trend analysis

## Dashboard Overview
- **$1.20M** total sales analyzed across **8,523 SKUs**
- **$141** average sales per item, **3.9** average rating across all outlets
- Interactive slicers for **Outlet Location Type**, **Outlet Size**, and **Item Type**, enabling drill-down analysis across Tier 1, 2, and 3 markets

## Key Insights
- **Tier 3 outlets drove the highest sales** at $472K, ahead of Tier 2 ($393K) and Tier 1 ($336K) — a strong signal for expansion priority
- **Supermarket Type1 accounted for 65% of total revenue** ($787.55K), making it the dominant outlet type by far
- **Grocery Stores had the best item visibility** (0.10), suggesting stronger product placement despite lower total sales
- Outlet establishment trends (2010–2022) show a sales peak around 2015 ($205K), useful for understanding growth patterns by outlet age
